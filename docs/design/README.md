## Концепт

Рабочий банковский кабинет с одним очевидным следующим действием. Красный — для действия/внимания, нейтральные поверхности — для данных, текстовый статус — в дополнение к цвету. Большая типографика используется в заголовке и суммах, без декоративных градиентов, плавающих шаров, карточек ради карточек и фиктивного процента одобрения.

Это авторская адаптация визуального языка Альфы под кейс, а не официальный макет банка. Onest сохранён из проекта; не выдаётся за фирменный шрифт Альфы. Навигация и тёмная карточка компании — дизайнерские решения прототипа.

## Состав

1. 01-dashboard.svg — desktop 1440×1000: компания, главное действие, реальные типы статусов, список заявок, фильтры и поиск.
2. 02-offer.svg — desktop 1440×1040: исходные 6 месяцев / предлагаемые 9, та же сумма, месячный платёж и общая переплата. Низкий платёж не маскирует рост стоимости.
3. 03-documents.svg — desktop 1440×1000: запрос специалиста, старый PDF не считается ответом, новая загрузка, заблокированная отправка и будущий ручной разбор.
4. 04-mobile.svg — 390×1110: те же задачи и контент в одну колонку, без уменьшенной десктопной таблицы.

SVG импортированы через редактор Figma в четыре отдельных фрейма. Текстовые слои и Onest проверены в панели Typography; надпись фильтра изменена штатным редактором. Визуально просмотрены все четыре экрана. Сохранение имени и четырёх фреймов подтверждено повторным открытием файла в независимой вкладке. Auto Layout, компоненты/переменные и прототипные связи ещё не созданы; плоские слои SVG не подменяют компонентную библиотеку. Статус HACK-022 — частично выполнено, требуется дальнейшая сборка и ревью.

Все компании, заявки и счётчики в макете — синтетические иллюстративные состояния. На экране присутствует пометка прототипа. Числа сравнения взяты из проверенного сценария проекта: 2 500 000 ₽, 20,5%, 6→9 месяцев; 441 931,47→302 040,30 ₽/мес.; суммарные платежи ≈2 651 588,82→2 718 362,70 ₽; переплата увеличивается ≈на 66 773,88 ₽. Приближённый расчёт без комиссий, окончательный график в договоре.

## Подключение

21 октября пользователь отклонил разрешение MCP на чтение/запись аккаунта и выбрал работу через браузер. OAuth не завершался; добавленный в этом проходе сервер `figma` удалён из локальных настроек Codex. Повторно не запрашивать этот доступ без нового указания пользователя. Ранее установленный плагин Figma не удалялся. Макеты созданы и редактируются через авторизованный браузер.

Справочные источники по рассмотренному варианту подключения: [официальная инструкция Figma для Codex](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/) и [описание MCP-конфигурации Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli). Рабочий способ для этой задачи — браузер, по прямому выбору пользователя.
