# Проверки и ограничения

GitHub Actions запускает три задания для pull request: backend, frontend и Compose. Проверять результат нужно у конкретного SHA, указанного при сдаче.

Базовая версия перед очисткой документации: `ba2c34e86f02a81607b64b3c234dacd8ba9fe0a6`, дерево совпадает с проверенным head `30e64bcbd854cbe58a06f363fdb940d74df909d3`. [Логи проверки](https://github.com/Makasinnnnnn/AlphaFutureHackaton/actions/runs/40287924015): **157 backend tests, 48 frontend tests, production build и 10/10 HTTP E2E**. Все пять Compose-сервисов стали healthy в чистом окружении. Эти результаты не следует приписывать произвольным будущим изменениям.

## Воспроизведение

- Backend: `cd backend` → `python -X utf8 -m pytest`. Нужна отдельная PostgreSQL БД с именем, оканчивающимся на `_test`, в `TEST_DATABASE_URL`: fixture пересоздаёт эту БД. Рабочую демобазу использовать нельзя.
- Frontend: `cd frontend` → `node --test scripts/*.test.cjs scripts/*.test.mjs` → `npm run build`.
- Работающее приложение: `python scripts/e2e_check.py --base http://localhost:8080`. Создаются новые синтетические заявки; существующие не удаляются.
- Ручные сценарии: [demo.md](demo.md) и [test-scenarios.md](test-scenarios.md).

Проверяются переходы состояний, дозапросы и повторная отправка, согласованность запроса/предложения, денежные округления и копейки, график договора, доступ по ролям, ошибки источников, ограниченные повторы, сессии и сценарий до моделируемой выдачи. Сохранённая OpenAPI соответствует приложению; Postman содержит 40 запросов.

## Границы

Это прототип на синтетических данных. Реальные реестры, БКИ, электронная подпись и банковские операции заменены симуляциями. Скоринг экспертный, не валидирован на кредитной истории банка. LLM опциональна; основной сценарий проверяется без неё. Интервью, нагрузочные метрики, качество реальной модели и продуктовый эффект не заявляются измеренными.

Демонстрационные пользователи и настройки не предназначены для production. Для публичной эксплуатации нужны отдельные настройки секретов, защита входа и периметра, управление пользователями и проверка безопасности окружения. Тесты не доказывают отсутствие любых дефектов.
