# Вёрстка полного кредитного пути — 21 октября 2026

## Результат

Интерфейс React приведён к единому визуальному направлению из docs/design: нейтральные поверхности, красный акцент #ef3124, Onest из локальных зависимостей, боковая навигация на desktop и видимая навигация на телефоне. Это адаптация визуального языка Альфы под авторский учебный прототип, не официальный интерфейс банка и не обещание идентичности каждому пикселю Figma.

Переработаны все существующие страницы и добавлена помощь:

| Страница / состояние | Реализация |
|---|---|
| /login | Вход, демосценарии, ошибки загрузки учёток, границы симуляции |
| / | Дашборд, реальные счётчики заявок, следующие действия, поиск, фильтры, пустые состояния |
| /new | Четыре шага: цель, условия, данные/документы, проверка и отправка. Справа расчёт и состояние сохранения, на телефоне одна колонка |
| /applications/:id — DRAFT | Черновик и документы, согласие, отправка |
| SUBMITTED / VALIDATION / ENRICHMENT / SCORING | Текущий статус, пояснение, живой маршрут |
| NEED_INFO | Запрос, старый/новый файл, доступность повторной отправки |
| APPROVED / COUNTER_OFFER | Условия, сравнение платежа и общей переплаты, принятие или отказ |
| SIGNING | Договор, суммы, согласие, полный график до подписи, симуляция подписания |
| ISSUED | Итог, договор, выдача как симуляция, полный график |
| REJECTED / CANCELLED | Результат, объяснение и доступные дальнейшие действия |
| /analyst | Очередь, поиск, фильтры, статистика синтетических заявок, таблица с настоящими ссылками |
| /analyst/applications/:id | Скоринг, проверки, аудит, форма решения/дозапроса, переход к форме по якорю |
| /help | Ответы о выписке, контрпредложении, дозапросе и графике; явные границы прототипа |

Вкладки аналитика поддерживают стрелки, Home/End и связанный tabpanel. У таблиц есть фокусируемая область горизонтальной прокрутки. Уведомления закрываются кнопкой и Escape, ошибки отмечания прочитанными показаны пользователю. Ошибки отзыва заявки больше не теряются. До загрузки/восстановления финансовых данных мастер не отправляет пользователя дальше с предположением, что компания не обслуживается в банке.

## Проверки

- Итоговая сборка TypeScript + Vite прошла: 38 модулей, новых зависимостей нет.
- Все 10 HTTP-сценариев scripts/e2e_check.py прошли на работающей системе. Прогон создал синтетические заявки CR-2026-000015…000025; основные данные не сбрасывались.
- В браузере создана CR-2026-000014: мастер, неверная нулевая сумма блокирует сохранение, сохранение и повторное изменение черновика, 2 500 000 ₽ на 6 месяцев, отправка, предложение на 9 месяцев, принятие, просмотр всех 9 платежей ДО подписи, демонстрационная подпись, ISSUED, перезагрузка с сохранённым результатом.
- В браузере CR-2026-000011: вкладки проверок и аудита; пустой запрос не отправляется; запрос специалиста → клиентский NEED_INFO → без нового файла кнопка заблокирована → загрузка синтетического PDF → повторная отправка → MANUAL_REVIEW. Содержимое файла не выдаётся за проверенное пояснение: его должен оценивать специалист.
- В браузере открыт отказ CR-2026-000020 с причинами; несуществующая /applications/999999 показывает ошибку с повтором.
- Проверены вход, dashboard, мастер, помощь, клиентская карточка, карточка аналитика и очередь на ширине 390 px. Замеры scrollWidth/clientWidth совпали: 375/375 либо 390/390 без вертикальной полосы. График намеренно имеет внутреннюю прокрутку 640 px, а не расширяет страницу.
- На desktop 1440 px визуально просмотрены вход, мастер, условия, карточки клиента/аналитика и очередь.
- На итоговой сборке ArrowRight переключает вкладку аналитика на проверки, End — на аудит; Escape закрывает уведомления; поиск очереди выводит пустое состояние.

Проверки браузера выполнены инструментом управления браузером. Новых файлов со скриншотами в репозитории нет. 62 backend-теста из предыдущего прохода здесь повторно не заявляются: backend не менялся. Независимое командное ревью и проверка на других браузерах/реальном устройстве ещё нужны.

## Запуск и ограничения

Обычный запуск остаётся через Docker Compose из README. Полная пересборка контейнеров в этом проходе была остановлена сетевой ошибкой TLS к Docker Hub при получении Dockerfile frontend; не отключали проверку сертификатов. Для проверки новых экранов выполнена локальная production-сборка, а её dist скопирован в уже работающий собственный контейнер alpha-hack-review-web-1. Поэтому новая вёрстка доступна по http://localhost:8080; после пересоздания web из старого образа потребуется обычная пересборка образа из текущих исходников. Полная Docker-пересборка этой версии пока не подтверждена.

Четыре фрейма Figma сохранены ранее: https://www.figma.com/design/lLExiDQXq0t2cMXDS7Vf65/. В этом проходе Figma не изменялась, поэтому новые варианты всех статусов не следует считать дополнительно нарисованными там. Пользователь выбрал работу с Figma через браузер; MCP read/write не разрешён и не запрашивается повторно.

Демо-политика актуальности/полноты выписки D006, независимое ревью, окончательный комплект сдачи и уточнение точного времени дедлайна остаются отдельными задачами. Никакие задачи команды автоматически не помечены Done.
