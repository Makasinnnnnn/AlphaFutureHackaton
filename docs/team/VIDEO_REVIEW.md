# Исправления по двум видеозамечаниям — 25 октября

Кружки разобраны локально: распознавание речи и сверка кадров. Исходные видео, кадры с лицом и сырые расшифровки не публикуются. Ниже только замечания о прототипе.

| Замечание | Реализация |
|---|---|
| Возврат в очередь при чтении длинной карточки требует крутить наверх | Дополнительная ссылка «Очередь заявок» в закреплённой боковой панели рядом с маршрутом |
| График хочется листать обычным колёсиком | Нативный wheel с passive:false двигает месяцы. На краях событие не перехватывается и продолжает двигать страницу. Поддержаны trackpad, line/page delta; Ctrl+wheel сохраняет zoom |
| В очереди слишком много пустых отступов | Уплотнены заголовок, статистические карточки и таблица, сохранена общая стилистика |
| Счётчики выглядят кликабельными | Теперь настоящие кнопки: ручная очередь, все отправленные, положительные решения. Время обработки остаётся обычным показателем. Добавлена отдельная кнопка обновления списка и статистики |
| Нужен выбор количества строк | 10/20/50/100 строк, страницы и общее число; поиск, смена фильтра или размера возвращают на первую страницу |
| Нужна кнопка быстрого возврата вверх | «Наверх» появляется после 400 px в очереди и карточке; на мобильной ширине расположена над нижней навигацией |

Фраза про отдельную кнопку во втором видео распознана неуверенно. Реализация разделяет навигацию по счётчикам и обновление, не выдавая предположение за дословное пожелание.

При реализации исправлены связанные несоответствия: старый API обрезал список на 200 заявках, а статистика включала скрытые черновики; добавлен `/api/analyst/applications/page`, сводка считает тот же сегмент отправленных заявок. Старый endpoint списка сохранён для совместимости. В карточке аналитика исправлено наложение длинных названий полей на значения.

## Проверка

- 95 backend-проверок на отдельной PostgreSQL `conveyor_test`: включая 205 заявок, равные timestamps, границы страниц/параметров, отсутствие черновиков и RBAC.
- 32 frontend-проверки: смена страницы/размера/поиска/фильтра, счётчики, обновление обоих ресурсов, «Наверх», направление/единицы wheel, отсутствие scroll trap на границах и при zoom.
- Production frontend build прошёл.
- В браузере: 10 строк из 44, переход на страницу 2 из 5, возврат наверх; дополнительная ссылка остаётся на top=96 при прокрутке карточки. Реальное колесо меняет scrollLeft 60→0 без прокрутки страницы, следующее событие у края прокручивает страницу.
- OpenAPI, Postman и docs/api.md обновлены. Полный HTTP E2E: 10/10; чистую сборку дополнительно проверяет GitHub CI.
- При ширине 390 px документ занимает 375 px; новые элементы управления не создают горизонтального переполнения страницы. На desktop закреплённый возврат расположен ниже шапки, названия полей компании не пересекаются со значениями.

Проверки и снимок очереди относятся к синтетическому локальному preview. Исследовательские выводы или эффективность для реального банка из этих видео не заявляются.
