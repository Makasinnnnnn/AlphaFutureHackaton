# Дополнительный локальный аудит, 25 октября 2026

Основание: прямой запрос пользователя на полную проверку логики и ошибок. Отдельная GitHub-карточка не предоставлена; этот аудит не меняет командные продуктовые решения. Базовый main: `9888870ed377b1a0df1e4c84eab6e4a489f4053c`. Исправления вынесены в отдельную ветку `fix/deep-audit-regressions`; публикация выполняется через отдельный PR без изменения main.

## Что исправлено

- График рассчитывает фактические денежные потоки в Decimal с округлением до копеек: платёж равен основному долгу плюс проценты, остаток согласован с погашениями, последний остаток равен нулю. Ранее для 1 000 000,99 ₽ сумма погашений составляла 1 000 000,98 ₽.
- Сумма заявки, изменение суммы, предложение аналитика и стоимость оборудования не принимают доли копейки: 422 вместо неявного округления базой данных.
- Поле суммы сохраняет десятичную запятую и дробную часть при редактировании/копировании. Ранее ввод `1 000 000,98` превращался в 100 000 098 ₽.
- NOT_FOUND от БКИ или ФНС трактуется как отсутствие необходимых данных: ограниченные повторы и ручное рассмотрение. Это не «чистая» история без долгов.
- Отчёт источника должен содержать запрошенный ИНН. Чужой или отсутствующий ИНН даёт ошибку интеграции.
- Некорректные типы/длины полей реестра и невозможные/будущие даты регистрации отклоняются до обновления карточки компании.
- Отключённые пользователи не получают токен при входе и не предлагаются в демо-списке.
- Банковские обороты для расчёта берутся из последнего непрерывного периода; старые месяцы за разрывом не завышают среднее.
- Повторная отправка NEED_INFO проверяет реальные требования на сервере. В allowed_actions нет RESUBMIT до заполнения данных и актуальных документов; прямой преждевременный запрос возвращает 409. Ручные запросы по-прежнему требуют новый документ относительно каждого снимка.
- Автоопрос начинается после отправки сохранённого черновика и ответа на дозапрос. Результат действия отменяет устаревший ответ опроса.
- Временная ошибка опроса не останавливает обновления; последнее состояние сохраняется, ошибка показывается с повторной попыткой и исчезает при восстановлении.
- Path-параметры идентификаторов ограничены диапазоном PostgreSQL INTEGER: 1..2147483647. Ошибочные значения возвращают 422, некорректный sub JWT возвращает 401, вместо ошибки базы и HTTP 500.
- Отсутствующие файлы /fonts/ и /assets/ возвращают 404 вместо HTML приложения с кодом 200.
- При смене шага формы выполняется переход к началу страницы; ошибки загрузки каталога/целей видимы и допускают повторную попытку.
- Кнопка «Наверх» скрывается при редактировании input/textarea/select и не перекрывает поле обоснования аналитика.

## Изменения контрактов

OpenAPI обновлена. Денежные поля имеют multipleOf=0.01, path ID имеют minimum=1/maximum=2147483647. RESUBMIT в allowed_actions отражает выполнение требований; до готовности endpoint /resubmit возвращает 409. При отсутствии отчётов ФНС/БКИ применяется передача специалисту, а не автоматическое решение. Банковские и загруженные обороты используют непрерывный период. Последний платёж может отличаться на копейки из-за округления денежных потоков.

## Оставшиеся ограничения

Это проверка демо-прототипа на синтетике, а не подтверждение production-безопасности или качества банковского скоринга. Сохраняются демонстрационные учётки/секрет, отсутствует ограничение попыток входа. Нельзя публиковать такую конфигурацию как production. Rate limit, управление реальными пользователями/секретами и защита публичного периметра требуют отдельной спецификации.

Styrene UI в репозитории отсутствует; используется предусмотренный Onest, возможны предупреждения о шрифте. В тестах остаётся deprecation warning Starlette/httpx. Они не скрыты и не выданы за исправленные.

Не проверялись реальные устройства/Safari, установка PWA через ОС, реальные внешние источники, реальная подпись/банковские операции, запущенная Ollama, нагрузка большого масштаба и CVE базовых Docker-образов. Браузерные снимки этого прохода сделаны при viewport 554×831; прежние матрицы разрешений не считаются доказательством текущего аудита. Скриншоты и обычные тесты не доказывают полное соответствие требованиям доступности.

Работающая версия оставлена на localhost:18080, API localhost:18000; Compose-проект alpha-future-audit. Демо-база сохранена, тестовые сценарии добавили синтетические заявки. Исходные загруженные изображения и персональные данные не использовались.
