# Дизайн кредитного кабинета

## Направление

Рабочий интерфейс предпринимателя: белые поверхности, светло-серый фон, спокойная типографика и красный акцент для основного действия. Без декоративных градиентов, выдуманных кредитных лимитов, обещаний одобрения и фиктивных процентов готовности.

Источники проверены 21 октября 2026:

- [Альфа-Бизнес Онлайн](https://alfabank.ru/sme/rko/internet-bank/) — контекст продукта. Страница найдена поиском; автоматическое чтение полного содержимого вернуло 502, поэтому детали экранов не считаются проверенными.
- [Alfa UI primitives](https://github.com/alfa-laboratory/alfa-ui-primitives) — открытые примитивы Альфы. Репозиторий архивный, не актуальное официальное руководство бренда.
- [Цветовые токены Core DS](https://github.com/core-ds/ui-primitives/blob/master/colors.json) — исторический red_brand `#ef3124`. Использован как референс.
- [Core components](https://github.com/core-ds/core-components) — библиотека React-компонентов и ссылка на Storybook. Не добавлена зависимостью: сохраняем стек и размер приложения.
- [React: derived state](https://react.dev/learn/you-might-not-need-an-effect) — фильтры вычисляются из данных и выбранного фильтра, без дублирующего состояния.

Это авторский дизайн прототипа в стилистике Альфы, не копия действующего интернет-банка и не официальный дизайн банка. Шрифт Onest уже был в проекте, распространяется локально; фирменный банковский шрифт не выдаётся за подключённый.

## Реализованные экраны

1. Дашборд: компания, ближайшее действие, три счётчика из реальных заявок; фильтры, поиск, пустое состояние и восстановление после ошибки; обороты с источником данных.
2. Контрпредложение: сумма и срок рядом; исходная и предлагаемая ставка/платёж; все платежи и переплата с явной пометкой приближения. Для овердрафта такое аннуитетное сравнение скрыто.
3. Дозапрос: новые документы обязательны; после отправки документы проверяет специалист, а не автоматическое одобрение.

## Токены и компоненты

Токены находятся в `frontend/src/styles.css`: красный `#ef3124`, белые поверхности, тёмный текст, существующие цвета состояний. Onest 400/500/600/700. Повторно используются кнопки, StatusChip, ErrorBox, Loading и TurnoverBars. Макет: контент до 1200px, основная колонка и 320px с данными компании; ниже 980px одна колонка; ниже 640px вертикальные метрики и карточки.

Состояния: загрузка, пустой список, ноль совпадений, ошибка API с повтором, данные клиента другого банка, активная заявка, дозапрос, контрпредложение, завершение. Статус обозначается текстом, не только цветом. Кнопки фильтров имеют aria-pressed; поиск имеет текстовую метку; таблица условий имеет заголовки строк/колонок.

## Figma

21 октября в браузере создан и сохранён [«Кредитный маршрут · Альфа-Будущее 2026»](https://www.figma.com/design/lLExiDQXq0t2cMXDS7Vf65/). Четыре фрейма: `01-dashboard` (1440×1000), `02-offer` (1440×1040), `03-documents` (1440×1000), `04-mobile` (390×1110). Импортированы SVG с отдельными векторными и текстовыми слоями; редактирование надписи и шрифт Onest проверены в UI. Все четыре экрана визуально просмотрены, облачное сохранение подтверждено независимым открытием файла в новой вкладке. Исходники, исследование и ограничения — [docs/design/README.md](../design/README.md).

Это отдельный визуальный концепт для обсуждения; React автоматически не обновлялся. Auto Layout, библиотека компонентов/переменных и кликабельные переходы ещё не сделаны. Поэтому HACK-022 нельзя считать полностью принятым. Официальный MCP `https://mcp.figma.com/mcp` добавлен в локальные настройки Codex; OAuth ожидает отдельного разрешения на чтение/запись аккаунта. Вход в Figma через браузер не подтверждает MCP-подключение.
