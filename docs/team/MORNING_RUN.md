## Доведённый участок HACK-007

Браузером пройден путь клиента ООО «Северный край»: выбор продукта, сохранение, отправка, переход к аналитику. Отдельной вкладкой аналитика выполнен ручной дозапрос. До загрузки кнопка клиента выключена; после синтетического PDF включается, ответ возвращается в MANUAL_REVIEW. Перезагрузка страницы сохраняет состояние. Проверен повторный запрос: ранее загруженный файл не закрывает новый запрос.

Найдены и исправлены два UX-несоответствия:

1. В ручном дозапросе будущий маршрут показывал автоматическую валидацию/обогащение/скоринг вместо возврата специалисту. Теперь предстоящие этапы: MANUAL_REVIEW → решение → договор → выдача. Добавлена API-регрессия.
2. Старый файл показывался как выполненная загрузка при выключенной кнопке отправки. Теперь написано, что файл загружен до текущего запроса, оформление готовности снято, действие называется «Добавить новый файл». Общая проверка готовности вынесена в hasPendingAnalystRequest, чтобы подсказка и кнопка не расходились.
