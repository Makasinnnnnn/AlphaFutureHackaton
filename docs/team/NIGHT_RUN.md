Исходный прототип опубликован в main, commit 72668fa. Доработки — [PR #24](https://github.com/Makasinnnnnn/AlphaFutureHackaton/pull/24), ветка feat/reliable-credit-route. PR оставлен для проверки командой; merge и независимое ревью не заявляются.

## Что изменено

- Исправлена потеря десятичной точки в CSV. NaN, infinity, слишком большие/отрицательные поступления, неполные строки, пустая история и будущие операции дают понятный отказ. Агрегатор дополнительно проверяет денежные значения. Диапазон 1e15 — техническое ограничение прототипа.
- Ручной запрос сохраняет список существовавших документов. Без нового документа resubmit возвращает 409; после загрузки ответ идёт обратно в MANUAL_REVIEW. Содержание проверяет аналитик; загрузка сама по себе не означает принятия документа.
- limits сохраняет лимиты первоначального запроса; offer_limits отдельно показывает лимиты на предлагаемый срок. requested_terms содержит исходный расчёт для сравнения. Сравнение переплаты скрыто для овердрафта и смены продукта.
- После трёх неожиданных технических ошибок этапа — MANUAL_REVIEW, аудит PIPELINE_ERROR и уведомление. После успешного шага счётчик сбрасывается; запись защищена блокировкой и проверкой версии. Добавлена миграция 0002.
- Дашборд: следующий шаг, реальные счётчики, поиск и фильтры, данные компании и источники оборотов. Контрпредложение показывает приблизительные суммарные платежи и переплату; итоговый график остаётся в договоре.
- Кроссплатформенные hash-lock файлы без смены существующих версий; на Windows добавлены условные зависимости. Защита тестовой fixture: сбрасывать можно только БД с суффиксом _test.
- CI: PostgreSQL/API-тесты, сборка frontend, Docker и 8 сквозных сценариев. Для совместимости Compose worker получил явную проверку живости процесса; продвижение заявок проверяет E2E.
