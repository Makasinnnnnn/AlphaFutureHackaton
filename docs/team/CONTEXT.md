# Контекст проекта

Обновлено: 21 октября 2026. Это исходный срез; после переноса поддерживается командой.

## Факты

- Хакатон «Альфа-Будущее» 2026, кейс «Умный кредитный кабинет предпринимателя».
- Команда из 5 человек; базовые навыки во всех областях, ИИ-ассистенты у всех. Оценка доступности — по 10–20 часов, всего 50–100 человеко-часов.
- Предпочтение команды: общий GitHub backlog, каждый сам берёт и добавляет задачи. Жёсткого распределения ролей нет.
- Онлайн-этап 19–26 октября; точное время/часовой пояс сдачи нужно подтвердить на платформе.
- Основной источник требований — PDF кейса, особенно стр. 6–7, 9–11, 13–15. Общий регламент 2026 и поля формы сдачи ещё нужно сверить.

## Обязательные свойства

Работающий веб-прототип с клиентским и банковским процессом, сохранением данных, последовательными состояниями, моделью риска и кредитного решения. Автономный запуск в Docker, синтетические данные, локальные mocks. Проверяемая версия не зависит от платных API/подписок/данных; для LLM допускаются открытые веса. Основной путь внутри продукта. Подпись и выдачу разрешено моделировать. При сдаче нужны GitHub/версия, README, lock-файлы, данные и учётки, THIRD_PARTY_NOTICES, архитектура, API/OpenAPI/коллекция, состояния, модель данных и тестовые сценарии.

## Переданный прототип

React/TypeScript/Vite + FastAPI/Pydantic/SQLAlchemy/Alembic + PostgreSQL + отдельный worker + mocks ЕГРЮЛ/ФНС/БКИ + Docker Compose. Два типа пользователей: CLIENT и ANALYST. Три продукта: оборотный кредит, оборудование, овердрафт. Скоринг экспертный, условия продукта вычисляются отдельным слоем. Ollama-подбор цели необязателен и имеет fallback на правила.

Исходный commit архива: `6ddf3c027d1103911990f16b446a62161bfd3bd2`. В копии архива не было remote и тега из README. Отдельный GitHub команды этим не проверен.

## Проверенные результаты

- 26 доменных тестовых случаев прошли 21 октября 2026.
- Парсер принимает NaN/inf; агрегатор сохраняет неконечные показатели. Будущие даты и разреженные месяцы проходят проверку полноты.
- Ручной ANALYST_REQUEST не учитывается условием готовности UI; стандартная проверка конвейера не отслеживает его исполнение. Выявлено по коду, полный браузерный сценарий пока не воспроизведён.
- Контрпредложение может менять срок, оставляя метаданные лимитов исходного срока. Нужна ясная семантика ответа.
- Полный Docker/API/E2E, frontend-сборка и браузерный путь не подтверждены. Документация о 41 тесте не означает, что все они прошли в текущем разборе.

## Предлагаемый продукт — ещё не утверждён

«Кредитный маршрут»: предприниматель получает понятные выполнимые условия, видит причины, данные и следующий шаг; аналитик получает контекст исключения. Основной кандидат для демонстрации — сохранить сумму, изменив срок, с честным сравнением платежа и общей стоимости. Выбор сегмента, UX и приоритетов подтвердить обсуждением и исследованием.
