- Очередь растягивала страницу до 823 px на планшетных 641/768/820 px: локальная прокрутка `.table-wrap` теперь действует при любой ширине.

- Нижняя навигация и «Наверх» учитывают safe-area. Вертикальная прокрутка у горизонтальных вкладок отключена.

## PWA: реализация и границы

Без новых npm-зависимостей: `manifest.webmanifest`, PNG-иконки 192/512, standalone launch, Apple metadata, инструкция `/install.html`, service worker только в production и secure context. Внизу кабинета есть ссылка «Как установить приложение». Иконки получены из той же SVG-геометрии бренда, что используется в интерфейсе.

Service worker кэширует **только публичный `/offline.html`**. API, документы, финансовые данные, токены, ответы HTML с данными пользователя и JS/CSS приложения в Cache Storage не сохраняются. Страницы запрашиваются из сети. При невозможности загрузки страницы показывается нейтральное сообщение о потере связи, без подтверждения банковских действий. Фоновой отправки, push и офлайн-кредитования нет.

Обновления: `/sw.js` — `no-store`, manifest и HTML — `no-cache`, JS/CSS имеют хеши. Новый worker не вызывает skipWaiting и не перезагружает открытую форму. При изменении офлайн-шаблона нужно обновлять версию `CACHE_NAME`. Очистка удаляет только старые кэши собственного префикса.

Для установки на телефоне нужен **HTTPS**. `http://localhost` подходит для проверки на этом компьютере; `http://192.168…` с телефона обычно не является secure context. Сам факт поддержки PWA не публикует сайт наружу.

Основание: [MDN — установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable), [MDN — service workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers). PWA добавлена по пожеланию пользователя, не как обязательное требование хакатона.

## Проверено

- 37 frontend-проверок и production build прошли. Новые проверки: область перехвата worker, отсутствие API/документного кэширования, online/offline navigation, очистка только собственного кэша, реальные размеры иконок, регистрация только в безопасном контексте и обработка её сбоя.
- HTTP: manifest, worker, offline page и обе иконки возвращают 200 с правильными MIME; у worker no-store, у manifest no-cache. Конфигурация Nginx проходит `nginx -t`.
- Реальная потеря связи: остановлен только контейнер web, перезагрузка управляемой страницы показала публичный offline notice; web запущен обратно, «Повторить подключение» вернул онлайн-страницу, затем работающий кабинет аналитика. Данные БД и остальные сервисы сохранены.

Не проверены: физические iPhone/Android, Safari/WebKit, реальная установка через меню ОС, экранная клавиатура, нестандартный системный масштаб и все размеры между выбранными точками. Утверждать абсолютную поддержку всех устройств по этому прогону нельзя. Полный CI проверяется перед слиянием отдельно.
