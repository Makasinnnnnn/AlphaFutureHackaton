# Исправления по разбору 24 октября

Основа: `main` 6dd453d. Из PR #24 перенесены только backend-исправления, миграция, регрессионные тесты и минимальная защита дозапроса на frontend. Новые формы, черновики, пагинация и уведомления main сохранены. Старый дизайн целиком не переносился.

Критерии: ручной дозапрос нельзя отправить без нового документа; ответ возвращается аналитику, автоматическое одобрение не допускается; NaN/inf/переполнение отсекаются; повторные ошибки воркера ограничены и передают заявку специалисту. Миграция 0002 добавляет счётчик технических ошибок.

Колокольчик стал прямым. Галочки маршрута заменены на центрированный SVG. Новые сообщения дозапроса содержат понятные тексты вместо EQUIPMENT_INFO/EQUIPMENT_INVOICE.

Добавлен опциональный OpenAI-совместимый адаптер: `LLM_PROVIDER=openai_compatible`, `LLM_BASE_URL` (включая `/v1`), `LLM_API_KEY`, `LLM_MODEL`. Контракт: `POST /chat/completions`; ответ JSON с `purpose`. Основной процесс работает без LLM; сетевой сбой, HTTP-ошибка или неверный JSON возвращают подбор к правилам. Для автономного запуска использовать локальный сервер открытой модели. Ollama остаётся режимом по умолчанию, LLM выключен.

Экспорт OpenAPI обновлён из кода. README больше не заявляет несуществующий финальный тег и наличие Styrene. Число тестов определяется сбором, а не устаревшей цифрой.

Для сдачи достаточно однозначного идентификатора версии: полного commit SHA или опубликованного тега. Имя `v1.0-submission` не обязательно. Актуальный порядок проверки версии: [SUBMISSION.md](../SUBMISSION.md). Этот отчёт описывает исторический проход 24 октября.

Проверка: 70 backend-тестовых случаев прошли на отдельном PostgreSQL `conveyor_test`, порт 55434. Production frontend-сборка и 17 frontend-проверок прошли. На обновлённом Docker-предпросмотре прошли 10/10 HTTP E2E: выдача, контрпредложение, документы, ручное решение, два раунда ручного дозапроса, отказ по просрочке, ликвидация, недоступное БКИ, права доступа и изменение срока. Без нового документа оба ручных дозапроса возвращают 409; с новым документом — MANUAL_REVIEW, оба перехода есть в аудите. В браузере проверены прямой колокольчик и центрированные SVG-галочки на реальной карточке. Один warning о deprecation httpx/Starlette не влияет на результат.
