## Как работать

1. Выбери свободную карточку, назначь себя и переведи в работу.
2. Проверь критерии приёмки и зависимости; одна активная задача на человека.
3. Сделай небольшой PR, приложи проверки, пригласи любого свободного участника на ревью.
4. Done — после проверки результата. Постоянных специализаций и закреплённых зон кода нет.

Перед запросом к ИИ: прочитать AGENTS.md, CONTEXT.md, DECISIONS.md и выбранную задачу.
